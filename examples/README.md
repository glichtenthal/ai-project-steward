# Worked Scenarios

These scenarios show the range of AI Project Steward. They are readable demonstrations, not claims that every model will produce identical wording.

1. [Complete project build](quick-demo.md) — a golden-path example covering choices, recommendation, approval, a decision record, implementation, and verification.
2. [Fast reversible change](fast-reversible-change.md) — evidence that the skill does not add unnecessary governance.
3. [Consequential deployment](consequential-deployment.md) — evidence that public, paid, security-sensitive, and difficult-to-reverse actions remain approval-gated.
4. [False completion](false-completion.md) — evidence that polished but disconnected behavior is not called finished.

The machine-readable cases and release methodology live in the [Behavioral Evaluation Suite](../evals/README.md).
