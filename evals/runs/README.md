# Evaluation Runs

Run records contain the case-by-case routing and behavioral judgments used to generate release results.

Retain only records that are safe to publish. Remove credentials, customer data, private workspace names, account identifiers, and unrelated conversation history from linked outputs.

Keep raw execution logs local. Publish only the reviewed, redacted output needed to support a result judgment.

Use `python3 scripts/evaluate.py init --help` from the repository root to prepare a run record.
